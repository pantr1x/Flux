# Zen Mode

Just you and your code. **Zen mode** hides the sidebar, tabs, output panel and status bar and puts your code in the middle of the screen.

- `Ctrl+Alt+Z` – turn Zen mode on or off
- `Esc` – leave Zen mode
- Move the mouse to the top to see the Run button.

Perfect for reading code or writing a long function without distractions.
