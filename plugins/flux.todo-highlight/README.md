# TODO Highlight

Never forget what is left to do. Write a comment with **TODO**, **FIXME**, **HACK**, **NOTE** or **BUG** and it lights up:

```python
# TODO: ask the user for their age
# FIXME: crashes when the list is empty
# NOTE: this uses the pygame library
```

- 🟡 **TODO**, 🔴 **FIXME / BUG**, 🟠 **HACK**, 🔵 **NOTE** – each has its own color.
- The **status bar** shows how many there are in the open file – click it to jump to the next one.
- `Ctrl+Alt+N` jumps to the next TODO.
