# Auto Rename Tag

Change `<div>` to `<section>` and the matching `</div>` becomes `</section>` automatically – and the other way round.

- Works in HTML, XML, PHP, Vue, Svelte, JSX and Markdown.
- Understands nested tags with the same name.
- Undo (Ctrl+Z) works as usual.

One of the most installed web extensions for VS Code.
