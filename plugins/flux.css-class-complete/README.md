# CSS Class Completion

Stop switching between `index.html` and `style.css` to remember a class name.

- Type `class="` and you get every class from **all .css / .scss / .less files** in the project, plus the `<style>` block of the page.
- Each suggestion says which file it comes from.
- Classes you already used in the attribute are not offered again.
- Works in HTML, PHP, JSX (`className`), Vue and Svelte.

Inspired by *HTML CSS Support* for VS Code.
