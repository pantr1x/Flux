# Error Lens

The most loved helper from VS Code, now in Flux: **errors and warnings are written right at the end of the line** where they are.

- ✖ Red for errors, ⚠ yellow for warnings, with a soft line background.
- Works in every language that shows problems (Python, JavaScript, HTML, CSS, JSON…).
- Commands (Ctrl+Shift+P): *Error Lens: turn on / off*, *Error Lens: show / hide warnings*.

Great for beginners – you see what is wrong immediately, while you type.
