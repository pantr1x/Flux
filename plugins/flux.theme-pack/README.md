# Theme Pack

Eight well-loved color themes for your code, ready to pick in **Settings → Appearance → Code theme** (or Ctrl+Shift+P → *Color theme*).

| Theme | Style |
|---|---|
| Gruvbox Dark | warm, retro, easy on the eyes |
| Solarized Dark / Light | the classic calm palette |
| Rosé Pine / Rosé Pine Dawn | soft pastel colors, dark and light |
| Ayu Mirage | modern, bright on dark blue-gray |
| Night Owl | made for coding late at night |
| Everforest | green, natural and relaxed |

Every theme also colors Python's smart highlighting (functions, classes, parameters). Uninstalling the plugin switches you back to a built-in theme.

**For plugin makers:** this plugin is a good example of `flux.themes.add()` – see `plugin.js`.
