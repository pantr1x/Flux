# Pomodoro Timer

Stay focused with the **Pomodoro technique**: 25 minutes of coding, then a 5 minute break.

- 🍅 The timer lives in the **status bar** – click it to start or pause.
- 🔔 Flux tells you when it is time for a break (and when the break is over).
- ⌨️ `Ctrl+Alt+T` starts / pauses the timer from anywhere.

## Commands
Open the command palette (`Ctrl+Shift+P`) and type **Pomodoro**:

- **Start / pause timer**
- **Reset timer**
- **Use short sessions (15 / 3 min)** – great for beginners
- **Use classic sessions (25 / 5 min)**
