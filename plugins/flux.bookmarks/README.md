# Bookmarks

Put a bookmark on the lines you keep coming back to.

| Shortcut | What it does |
| --- | --- |
| **Ctrl+Alt+K** | add / remove a bookmark on the current line |
| **Ctrl+Alt+L** | next bookmark |
| **Ctrl+Alt+J** | previous bookmark |

- A blue mark appears next to the line and in the scrollbar.
- Bookmarks move with the line while you type and are remembered after restart.
- The status bar shows how many you have – click it to jump.
- You can change the shortcuts in Settings → Shortcuts.
