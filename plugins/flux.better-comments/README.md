# Better Comments

Make comments easier to scan – like the VS Code extension of the same name.

| Write | Looks like |
| --- | --- |
| `# ! do not change this` | red – important |
| `# ? why is this slow` | blue – a question |
| `# TODO add a menu` | orange – something to do (also FIXME, HACK) |
| `# * this is the main loop` | green – highlighted |
| `# // old code` | grey and crossed out |

Works with `#`, `//`, `--`, `/*` and `<!--` comments, so in Python, JavaScript, Java, C++, Rust, Lua, HTML, CSS…
