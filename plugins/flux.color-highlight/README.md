# Color Highlight

CSS already shows color squares – now **Python, JavaScript, JSON, Markdown and more** do too.

- `#6b5cff`, `#fff`, `rgb(255, 120, 0)` and `rgba(…)` get a small square in front.
- Click the square to pick a new color – the text changes for you.
- Handy for pygame / tkinter colors, chart colors in JavaScript or config files.
