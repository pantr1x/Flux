# Lorem Ipsum

Need some text to see how your web page looks? Type **`lorem`** and press **Tab**.

| Type this        | You get                          |
| ---------------- | -------------------------------- |
| `lorem`          | a paragraph of placeholder text  |
| `lorem-p`        | `<p>` with a paragraph (HTML)    |
| `lorem-list`     | `<ul>` with three items (HTML)   |

Also in the command palette (`Ctrl+Shift+P` → *Lorem*): insert a sentence, a paragraph or three paragraphs.
`Ctrl+Alt+L` inserts a paragraph right where your cursor is.
