# Glass UI

Makes Flux look like frosted glass:

- Panels are more see-through, with a stronger blur behind them.
- Buttons, the active tab and the selected project softly glow in your **accent color**.
- The text cursor glows too.

Change how strong the glass is with **Ctrl+Shift+P → Glass UI: strength** (light, medium, strong). It looks best with a colorful wallpaper and *Background: Wallpaper* in Settings → Appearance.

**For plugin makers:** a small example of `flux.ui.addStyle()` and `flux.storage` – see `plugin.js`.
