# Indent Rainbow

In Python the indentation decides what belongs to an `if`, a `for` or a function. With Indent Rainbow every level has its own soft color, so blocks are easy to see.

- 🟨🟩🟪🟦 one color per level.
- 🟥 Wrong indentation (a tab, or 3 spaces instead of 4) turns **red** – a very common reason for `IndentationError`.
- Only the visible part of the file is colored, so it stays fast in big files.
