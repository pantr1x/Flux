# Snippet Pack

Short words that turn into whole pieces of code. Type the word, pick it from the list and press **Tab** – then Tab again to jump to the next spot.

| Language | Snippets |
| --- | --- |
| Rust | `main` `fn` `pln` `struct` `impl` `match` `for` `test` `input` |
| Go | `main` `fn` `iferr` `pl` `for` `struct` |
| Java | `main` `sout` `class` `fori` `foreach` `scan` `try` |
| C++ | `main` `cout` `cin` `fori` `vec` `class` |
| C# | `cw` `rl` `class` `prop` `foreach` |
| JavaScript | `clg` `af` `qs` `ael` `fetchj` `timeout` |

Python and HTML snippets are already built into Flux.
