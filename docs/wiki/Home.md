# Flux wiki

**Flux** is a small, fast code editor for Windows. It has one-click **Run**, **Live Server**, **Claude AI**, **GitHub** and **plugins**. It updates itself.

- Download: [pantr1x.github.io/Flux](https://pantr1x.github.io/Flux/)
- What's new: [Releases](https://pantr1x.github.io/Flux/#releases)

## Plugins (mods)

Plugins add new features to Flux: commands, buttons in the status bar, snippets, color themes and whole new looks.
